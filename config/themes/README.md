# Дизайн-код тем TUI

Единая система цветов для всех тем OpenCode. Источник истины — не сами
JSON-файлы, а генератор `scripts/generate-themes.mjs`: он хранит карту ролей
(какой токен за что отвечает) и палитры, а `config/themes/*.json` генерирует.
Править руками можно, но при следующем запуске генератора изменения
затрутся — правильный путь: изменить генератор и перегенерить.

## Правила

1. **Нейтрали — одна шкала `gray`.** Фоны, поверхности, рамки, приглушённый
   текст, операторы и комментарии сидят только на ней.
2. **Акцент — один цвет на тему.** Слот `orange` в генераторе всегда несёт
   акцент, `interactive` и `accent` всегда указывают на него. Акцент отвечает
   за: кнопки, фокус/выделение, ссылки, заголовки, элементы списков, статусы
   running/unread, заголовки diff-хунков. Акцент у темы ровно один и он везде
   одинаковый — бренд и действие не расходятся.
3. **Вторичный цвет — слот `blue`.** Только для второстепенного: подписи
   ссылок (linkText), нумерация списков, подписи картинок, `feedback.info`,
   типы в синтаксисе. Он спокойный и никогда не конкурирует с акцентом.
4. **Семантика общая для всех тем.** `red/yellow/green` одинаковы во всех
   темах: ошибка всегда один и тот же красный, успех — один и тот же зелёный.
   Смысл цвета не сдвигается между темами.
5. **`purple` и `cyan` — только в `categorical`** (спиннеры, категории
   графиков). В интерфейс они не протекают.
6. **Синтаксис и markdown — максимум шесть ролей**, и роли те же, что в
   интерфейсе: keyword/function/heading/listItem — акцент, string/code —
   зелёный, number/emphasis — жёлтый, type/linkText — вторичный, операторы и
   комментарии — нейтрали.

## Темы

| Имя                | Характер                                                              |
| ------------------ | --------------------------------------------------------------------- |
| `accent-ember`     | Тёплый оранжевый акцент, деним-синий вторичный — ближе всего к духу v1 |
| `accent-ocean`     | Холодный синий акцент, тиловый вторичный                              |
| `accent-forest`    | Мшисто-зелёный акцент, тёплый золотой вторичный                       |
| `accent-graphite`  | Почти монохром, серебристый акцент — «тихий» вариант                   |
| `lucent-orng-contrast` | Контрастная тема из раннего набора (не из этого дизайн-кода, оставлена для совместимости) |

Все темы `accent-*` имеют тёмный и светлый варианты. Текущая выбрана в
`cli.json`; переключить можно в TUI: `Ctrl+P` → настройки → Theme
или команда `/theme`.

## Как добавить тему

1. В `scripts/generate-themes.mjs` добавь запись в `THEMES`: имя файла,
   ramps `orange` (акцент) и `blue` (вторичный) по 9 ступеней (100–900).
2. `node scripts/generate-themes.mjs` — сгенерит/обновит JSON в
   `config/themes/`.
3. `scripts/install.sh` (или `custom-opencode-update`) разложит темы в
   `~/.config/opencode/themes/`.
4. Выбрать тему: `cli.json` → `"theme": {"name": "..."}` или через `/theme`.

Ступени ramp'а: `100` — самый светлый, `900` — самый тёмный. Для тёмных тем
акцент используют ступени 300–500 (текст/состояния) и 500–700 (кнопки), для
светлых — зеркально 600–800. Контраст текста на акцентной заливке проверяй
визуально перед коммитом.
